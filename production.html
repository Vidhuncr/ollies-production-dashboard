Add Order Line

Enter an S# when available. Leave it blank and the system will create an internal “No S#” order reference. Ship Month is required for both.

Add Future Stock Need

Use this only for forecast or inventory production that is not a customer order.

Change Order Requirement

Managers and administrators can change the required amount or ship month. The amount cannot be reduced below production already recorded.

Record Produced Batch

First select exactly which S# or no-S# order this production is for. Record the labor rate and hours used for this batch.

Produce for Future Stock

This production is not linked to an S#. Matching production automatically reduces the oldest open no-S# need.

Production Needs Without S#

Managers can correct requirements. Administrators can delete needs that do not yet have production.
